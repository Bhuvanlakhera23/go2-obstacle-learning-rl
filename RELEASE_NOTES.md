# Technical report V1.1.0

Bhuvan Lakhera and Deepan Muthirayan · ARK Foundation Robotics Lab,
Plaksha University, India.

*Experience Allocation and Acquisition–Retention Trade-offs in Blind Quadruped
Obstacle Learning* — A Single-Seed Quadruped Reinforcement Learning Simulation Study.

Nominal explicit 16–18 cm detector-defined completions:

- Fixed-Mixture Policy: **117/128**.
- Adaptive-Frontier Policy: **47/128**.
- Pretrained Reference: **1/128** (historical, not equal-budget control).

The matched trained arms use one common training seed, the same prior/reward and
equal 131,072,000-transition budgets. Different hard-task exposure accompanies
the acquisition gap; it is not a causally isolated mediator. Retention costs and
adaptive-over-fixed counterexamples are reported.

This is a development **technical report**, not a peer-reviewed conference
publication or independently contact-validated traversal result. Independent
contact/visual ground truth, reward-OFF ablation, multi-training-seed replication
and hardware-transfer evidence are absent. No new experiments accompany this release.

The payload includes the manuscript, six SVG/PNG figure pairs, eleven numerical
tables, reproduction code/notes, citation, bibliography and integrity hashes.
Report assets are CC BY 4.0; included code is MIT. Original checkpoints,
simulator sources, robot assets, private logs and private Git history are excluded.
No Zenodo deposit is published automatically and no DOI is assigned here.
