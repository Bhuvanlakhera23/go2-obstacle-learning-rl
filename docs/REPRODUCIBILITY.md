# Reproduce the report figures offline

From the repository root, with Python 3.10+, NumPy and Matplotlib:

```bash
F02B_REBUILD=$(mktemp -d)
env CUDA_VISIBLE_DEVICES= PYTHONDONTWRITEBYTECODE=1 \
  python3 scripts/render_figures.py --tables tables --output "$F02B_REBUILD/figures"
python3 scripts/verify_public.py
```

The output leaf must be absent. These are CPU-only plotting/integrity commands:
no simulation, policy inference, Torch/CUDA or training. SVG text remains editable.
The renderer uses packaged tables and a fresh plotting cache; no private machine
path, checkpoint, experiment source or network call is needed. Rendering versions
are recorded in `figures/render_receipt.json`; cross-platform byte-identical
images are not promised.

RC2 changes policy/arm labels only in CSVs. Every other cell, including numerical
strings and original `source` trace fields, is preserved. The
[identity appendix](POLICY_IDENTITY_MAPPING.md) maps public names to original
policy keys/checkpoint filenames and exact hashes. Protected artifacts are not
included or renamed. Original records/source are required to recheck historical
collection; they are not promised as publicly available or licensed by this report.

The 6,912 first-episode records span three policies, three suites and two
evaluation seeds. The learning comparison remains one matched seed-73 pair.
Saved cumulative training outcomes are not held-out learning curves; exposure
time is not wall time or an independent contact count. Continuous metrics are
equal episode means, with vx/vy in m/s, yaw rate in rad/s, torque-squared in Nm²
and squared raw-action increments in raw action units². No new scientific result
is generated by these reproduction commands.
